REST API Endpoint: POST /api/qr/decode/

Integrate QR decoding programmatically into your scripts, mobile apps, or billing automation workflows. Accepts multipart image file uploads or JSON base64 payloads.

cURL Multipart File Upload:
curl -X POST http://127.0.0.1:8000/api/qr/decode/ \
  -F "image=@/path/to/invoice_qr.png"
JavaScript Fetch JSON Response:
const formData = new FormData();
formData.append('image', fileInput.files[0]);
const res = await fetch('/api/qr/decode/', {
  method: 'POST',
  body: formData
});
const data = await res.json();
console.log(data.data, data.parsed);
